# ROB 511 — Project 3 Portfolio

**Haonan Ping · Fall 2026 · University of Michigan**

This repository contains the public portfolio website for Project 3, Forward
Kinematics: a custom desk-arm model, a four-state FSM choreography, a recording of
the external viewer driven by the actual runtime, and an explanation of the
implementation.

The graded runtime and coursework implementation are not included here.

The site is plain HTML, CSS, and JavaScript. GitHub Pages can serve it directly from
the root of the `main` branch. The video is bundled, so visitors do not need a local
Python server or a separate video-service account.

The robot uses custom primitive geometry; no Fetch robot assets are used.
